# Research: faucet handle adapter (seed)
- Valve stem diameter and number of splines vary by manufacturer, so handles and adapters are not universal.
- Some lever kits use interchangeable inserts or an adapter sleeve with set screws to fit several stem sizes.
- Set screws can loosen with prolonged use; recheck tightness periodically.
- Identify the brand and model number or stem spline count before buying; match against the listing's stated compatibility.
- Knob and lever handles can sit at different heights; check trim and escutcheon fit.
- Cartridge and ceramic disc valves use different stems; listing must name the valve type or faucet series.
- Levers need less grip and finger dexterity than round knobs and can be pushed with a palm or wrist.
- Many OEM adapter kits are repair parts, not accessibility products; judge lever length and one-handed use.
- Slip-on turner extenders typically list a stem size and thread depth; measure first.
