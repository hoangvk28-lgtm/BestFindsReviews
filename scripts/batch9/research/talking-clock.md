# Research: talking clock

- The simplest talking clocks use one large button: press once for the time, press again for the day and date.
- Voice quality matters: many users find a lower, male voice easier to hear, though it varies by person.
- A volume control or high/low switch lets the clock suit different hearing levels; check the default is not startlingly loud.
- Look at the number of steps needed to set the time and alarm; tiny controls and long sequences make setup hard.
- Spoken setup prompts let blind users set the clock without sighted help.
- Alarm and hourly time report are common features on simple talking clocks.
- Low vision users benefit from high contrast displays (black on white or white on black) and non-glare surfaces.
- Button size, raised shape and contrast help people find the button by touch.
- Battery powered units are portable; AC powered units avoid battery changes but need an outlet.
- Pocket or keychain talking clocks suit travel but have small, quiet speakers.
- Atomic (radio-controlled) clocks set themselves from a daily signal and handle daylight saving automatically.
- Medication reminder and recordable voice messages help people who want prompts, but add setup complexity.
- Day-of-week and date announcements help people who lose track of days.
