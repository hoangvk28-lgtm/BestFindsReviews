# Wi-Fi extender research notes

- Extenders improve coverage; they do not raise the speed of the internet plan. Listings from TP-Link say this explicitly.
- Match the extender generation to the router generation (Wi-Fi 5 vs Wi-Fi 6); a weaker extender becomes the bottleneck.
- Dual band extenders use 2.4 GHz for range through walls and 5 GHz for speed over shorter distances.
- Tri-band extenders dedicate a second 5 GHz radio to the link back to the router, reducing the speed penalty.
- Older single-band extenders use one radio for both router link and devices, roughly halving throughput.
- Best placement is roughly halfway between the router and the dead zone, where the signal is still strong.
- Placing the extender inside the dead zone only rebroadcasts a weak signal.
- Plug into a wall outlet at chest height, away from large metal objects and microwaves.
- An extender is a cheap fix for one weak area; mesh is better for several dead rooms.
- Mesh systems give one network name and seamless handoff; many extenders create a second network name.
- Ethernet ports on an extender allow a wired connection for a TV or console.
- WPS push-button pairing is the simplest setup route; app or browser setup is the fallback.
- Some ISP-branded pods (such as xFi Pods) work only with the provider's rented gateway.
- Standalone extenders from third parties generally pair with any router that has Wi-Fi.
- Coverage square-footage figures are best-case numbers in open space; walls reduce them.
